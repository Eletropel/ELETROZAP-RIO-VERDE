# Eletropel • Central WhatsApp — Rio Verde

## Fluxo
1. Abra o painel.
2. Importe o Excel/CSV.
3. Clique em **ABRIR WHATSAPP** ou avance para o próximo cliente.
4. O Chrome abre o WhatsApp Web com o contato e a mensagem personalizada.
5. A extensão tenta preparar automaticamente o convite como **imagem + legenda**.
6. Confira a prévia e pressione **Enter** para enviar.

## Instalar a extensão
1. Abra `chrome://extensions`.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione a pasta `extension` deste projeto.
5. Abra/recarregue o WhatsApp Web.

## Observação
O WhatsApp Web altera a estrutura interna com frequência. A extensão usa os elementos de composição de mídia disponíveis no navegador; se o WhatsApp mudar esses elementos, o seletor pode precisar ser atualizado.

O projeto não automatiza o clique final de envio.
